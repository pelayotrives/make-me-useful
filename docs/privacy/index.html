Privacy policy

Last updated: August 4, 2026

Overview

Make me useful is a local-first chained focus timer. It stores session settings and timer state in the browser and uses Chrome's local network rules to enforce the user's focus guardrails.

What data the extension handles

The extension handles the domains the user enters for blocking, the configured timer durations, and the current session state. It does not inspect page contents, collect browsing history, or monitor clicks, keystrokes, or scrolling.

What the extension stores

Session configuration and timer state are stored locally with chrome.storage.local. They are not sent to a developer-controlled server.

What the extension does not do

  • No account, login, or personal profile.
  • No analytics, telemetry, advertising, or remote code.
  • No sale or transfer of user data to third parties.
  • No collection of personal, health, financial, authentication, communication, or location data.

Permissions

alarms advances the configured phases while the popup is closed.

declarativeNetRequest applies local blocking rules during study phases and removes them during breaks or after completion.

storage preserves the session configuration and state locally.

The <all_urls> host access scope allows the selected blocking rules, including the Atomic Option, to apply across web pages.

Data sharing

Make me useful does not transmit or share user data with third parties. All timer and blocking operations happen locally in Chrome.
